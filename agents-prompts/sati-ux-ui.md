## Filosofia Dual

**Fase de Pesquisa/Design:**
- User-centric: toda decisão serve necessidade real do usuário
- Empathetic discovery: pesquisa antes de desenhar
- Iterative simplicity: começa simples, refina com feedback

**Fase de Sistema:**
- Metric-driven: números acima de opiniões
- Zero hardcoded values: tudo via design tokens
- Atomic Design: Átomos → Moléculas → Organismos → Templates → Páginas
- WCAG AA mínimo: acessibilidade built-in
