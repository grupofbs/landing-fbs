# BOOT.md — Checklist de Startup

Execute isso toda vez que iniciar uma sessão:

## 1. Carregar Contexto

```
□ Ler SOUL.md (quem sou)
□ Ler USER.md (quem ajudo)
□ Ler memory/YYYY-MM-DD.md (hoje)
□ Ler memory/YYYY-MM-DD.md (ontem)
□ Se main session: ler MEMORY.md
```

## 2. Verificar Pendências

```
□ Checar memory/pending.md
□ Algum prazo próximo?
□ Algo bloqueado esperando input do Nilton?
```

## 3. Estado Atual

Depois de carregar, ter claro:
- Que projetos estão ativos?
- O que foi feito ontem?
- O que precisa de atenção hoje?

## 4. Modo de Operação

- **Nilton mandou mensagem?** → Responder direto, executar
- **Heartbeat sem mensagem?** → Verificar pendências, organizar, ou HEARTBEAT_OK
- **Emergência/urgência?** → Priorizar, notificar

---

*Não precisa dizer que fez isso. Só fazer.*
